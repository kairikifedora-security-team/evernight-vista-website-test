Evernight Vista 44.0.1 Released:Enhance your experience!

Release Date

July 29th,2026

Introduction

Evernight Vista is based on the Fedora distribution and is a Fedora-based distribution that allows beginner users to get started easily with zero barriers. It is committed to providing a smooth and fast user experience. This is the summer update summary, bringing hardware support, new features, and bug fixes.

WSL Platform

Supports using Evernight Vista on Windows 10 version 2004 or later and Windows 11 operating systems (requires Windows Subsystem for Linux to be installed, and it must be WSL2)

Hardware Support

Joystick: Now supports the Beitong Kunpeng 70 NTE Edition Controller (BTP-KP70C), thanks to VegetablCat on GitHub for providing the patch source code

Keyboard: Fixed the issue where the keyboard of Xiaomi Book Pro 14 2026 model does not work without adding any kernel parameters

New UI & New Features

By default, use the Darkly appearance engine, making the interface of konsole and dolphin file manager blur and transparent by default

Taskbar floating returns and taskbar style updated

GRUB2 Boot Interface Update

The input method skin is designed using SVG, compatible with high resolution and HIDPI technology

Add One key Install Practical tool

The Linyaps App Store has officially upgraded to the community version, supporting multiple languages

Added DNF5 graphical installation, allowing easy one-click installation, updating, and removal of RPM packages

System accent color update

Added practical CLI commands, such as the one-click update command 'update', so there is no need to enter the complex dnf5 command line anymore.

Added terminal font symbol support for certain distributions.

Significant improvements to boot animation and cursor.

The Klassy settings entry is restored and the UI has been translated.

Features Enhanced & BUG Fixes

  • Fsearch updated to version 0.3 stable; the home and mnt directories are automatically indexed on first launch.
  • Linyaps Store does not require password verification when installing, uninstalling, and updating Linyaps software.
  • Fixed the issue during the OOBE stage where a laptop could not continue setting up the operating system after being closed and then awakened.
  • Fixed the inconsistency between Dolphin in the root environment and the default Evernight Vista appearance.
  • Removed the scx-sched component due to performance issues with scx-sched.
  • Secure boot policy updated.
  • By default, use mksquashfs to package installation files.
